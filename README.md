## Quick Start

Open your terminal and run the `minhyuk` CLI like this

```bash
npx minhyuk
```

```text
Options:
  -a, --about       Show a short introduction and story
  -c, --career      Show career / work history
  -p, --projects    Show featured projects
  -s, --skills      Show tech stack
  -e, --education   Show education
  -g, --github      Open GitHub
  -b, --blog        Open blog
  -r, --resume      Open resume
  -l, --linkedin    Open LinkedIn
  -m, --email       Print email address
  -w, --web         Open portfolio website
  -V, --version     Output the version number
  -h, --help        Display help for command
```
